# Agent Fleet Terminal UI

A modern, terminal-inspired React frontend for the Agent Fleet orchestrator. Built with React 18, TypeScript, and Vite.

## Features

- **Real-time Worker Monitoring**: Split panel layout with worker list and streaming logs
- **Terminal-Style Output**: Monospace fonts, ANSI color support, and auto-scrolling logs
- **Command Palette**: Quick access to all actions via `Cmd+K` / `Ctrl+K`
- **Task Management**: Create and manage tasks with YAML/JSON editor
- **Workspace Configuration**: Inline configuration editor for orchestrator settings
- **Keyboard Shortcuts**: Navigate and control everything with keyboard
- **Search & Filter**: Search across all logs in real-time
- **Mock Data Mode**: Fully functional with simulated worker events and log streaming

## Quick Start

### Prerequisites

- Node.js 18+
- npm 9+

### Installation

```bash
cd frontend/terminal-ui
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:3000`

### Build

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd+K` / `Ctrl+K` | Open command palette |
| `Cmd+N` / `Ctrl+N` | Create new task |
| `Cmd+,` / `Ctrl+,` | Open settings |
| `↑` / `↓` | Navigate command palette |
| `Enter` | Execute selected command |
| `Esc` | Close modals/palette |

## Usage

### Monitor Workers

The main dashboard shows a split-panel view:
- **Left Panel**: List of all workers with status indicators
  - Green dot (●): Active
  - Yellow half-circle (◐): Idle
  - Red X (✖): Error
  - Gray circle (○): Offline
- **Right Panel**: Streaming logs from selected worker

Click on any worker to view its logs. Use the search box to filter log entries.

### Create Tasks

1. Press `Cmd+N` or use command palette (`Cmd+K` → "Create New Task")
2. Enter task name
3. Select task type (Flow or Command)
4. Edit the YAML/command configuration
5. Click "Create Task"

**Flow Example:**
```yaml
name: build-and-test
steps:
  - name: install
    action: npm install
  - name: build
    action: npm run build
  - name: test
    action: npm test
```

**Command Example:**
```bash
command: ./deploy.sh production
```

### Configure Workspace

1. Press `Cmd+,` or use command palette → "Open Settings"
2. Configure:
   - Orchestrator URL (WebSocket connection)
   - Log level (debug, info, warn, error)
   - Max log entries to keep in memory
   - Auto-reconnect setting
   - Theme (currently dark only)
3. Click "Save Changes"

### Use Command Palette

Press `Cmd+K` to open the command palette. Start typing to filter commands:
- Create new tasks
- Open settings
- Refresh data
- Clear logs
- Export logs

Navigate with arrow keys and press Enter to execute.

## Mock Data

The application runs in mock mode by default, simulating:
- 4 workers with different statuses
- Real-time log streaming (2-5 second intervals)
- Worker status updates
- Task queue management

Mock data is generated by `MockDataService.ts` and includes:
- Random log messages with varying levels
- Worker statistics updates
- Simulated network activity

## Design Philosophy

This UI is inspired by modern terminal applications with the UX benefits of a GUI:
- **Monospace Fonts**: All text uses monospace for that terminal feel
- **Dark Theme**: Tomorrow Night color palette
- **Minimal Borders**: Clean, focused interface
- **Keyboard First**: Every action accessible via keyboard
- **Real-time Updates**: Live streaming logs with auto-scroll
- **Quick Actions**: Command palette for power users

Think VS Code terminal meets Vercel dashboard.
