# Spec: CLI Status and Next Steps

**Created:** 2026-08-22
**Version:** v1.0
**Status:** Approved -- v1.0 -- 2026-08-22 -- 11/11 questions resolved; 13 audits complete
**Iteration:** 1

## Summary

This spec covers the harmonization of all CLI tools in the Wadeck ecosystem: flow-cli, task-cli, wdrive, violations-framework, and the scrapers (assurance, whatsapp, chatgpt). It documents the target architecture for distribution, config directories, auto-update, shared infrastructure, and the ordered migration plan. It replaces the informal plan at `.claude/plans/2026-08-22_cli-status-and-next.md` with a structured, auditable specification.
