allowed-tools:
    - Bash
---

Provide a script to run that outputs the current date and time as a timestamp in the format: YYYY-MM-DD_HH-MM (e.g., 2025-12-14_14-30).

For advanced usage, see examples.md.

Run the helper script:

```bash
node .claude/skills/get-timestamp/scripts/timestamp.js
```
